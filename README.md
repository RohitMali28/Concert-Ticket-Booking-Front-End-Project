Concert Ticket Booking System

This project is a simple Concert Ticket Booking System built using HTML, CSS, and JavaScript. It allows users to select a concert date, venue, ticket type, quantity, and view a booking summary with dynamic calculations. The system ensures proper form validation and error handling, guiding users through a seamless booking process.
Features

   •	Concert Date and Venue Selection: Users can choose from a list of available concert dates and venues.

   •	Ticket Type and Quantity Selection: Users can select a ticket type (General Admission or VIP) and specify the number of tickets they wish to purchase.

   •	Dynamic Booking Summary: The system displays a summary of the booking, including concert details, ticket type, quantity, and total price, which updates dynamically as users make changes.

   •	Form Validation and Error Handling: The system ensures all required fields are filled in before proceeding with the booking and provides error messages if any required input is missing.

User Stories

 User Story 1: Concert Date and Venue Selection

  As a user, I want to select a concert date and venue so that I can book a concert near me.

   •	The user can select a concert date and venue from a list of options.

   •	The selected date and venue are displayed in the booking summary.
   
 User Story 2: Ticket Type and Quantity Selection

  As a user, I want to choose the type of ticket (e.g., General Admission or VIP) and the number of tickets I want to purchase so that I can customize my booking.

   •	The user can select a ticket type from a dropdown.

   •	The user can specify the number of tickets using a numeric input.

   •	The total price is calculated based on the ticket type and quantity.

 User Story 3: View Booking Summary

  As a user, I want to see a booking summary after selecting my tickets so that I can review my purchase before finalizing it.

   •	The user can see a summary that includes concert details, ticket type, quantity, and total price.

   •	The summary updates dynamically as the user changes selections.

 User Story 4: Form Validation and Error Handling

  As a user, I want the system to validate my input so that I cannot proceed without selecting all required fields.

   •	The user receives an error message if any required fields (e.g., concert date, ticket type) are missing.

   •	The booking cannot proceed until all required fields are correctly filled in.

Acceptance Criteria

 Concert Date and Venue Selection

   •	The user must select a concert date and venue before proceeding.

   •	The selected details (date, venue) should be displayed in the booking summary.

Ticket Type and Quantity Selection

   •	Users can select a ticket type (General Admission: $80, VIP: $150) from a dropdown menu.

   •	The total price is calculated based on the selected ticket type and quantity.

Booking Summary

   •	The correct details (concert, ticket type, quantity, price) should be displayed in the booking summary.
 
   •	The summary updates dynamically when the user changes their selection.

Form Validation

   •	An error message is displayed if required fields are missing when the user tries to confirm the booking.

   •	Users cannot proceed until all fields are filled in correctly.


Technologies Used

   •	HTML5: For structuring the content and building the form.

   •	CSS3: For styling the layout and ensuring responsiveness.

   •	JavaScript: For dynamic behavior, validation, and updating the booking summary.
